# 资料模块

## 导航与编辑

左侧纵向模块栏提供书稿、人物、事件、世界观、设定。书稿内切换章节 / 笔记；其他模块使用资料目录。固定导航保存当前模块，不随编辑区切换。两个编辑区可分别打开任意类型的文档。

点击目录项会在当前活动编辑区打开文档。各区域标题的选择器只改变本区内容。人物、事件和章节共用编辑器、四向位置控制与布局撤销；关闭辅助区不删除文档。属性中的引用在其所属编辑器打开，保留其他分栏。

## 内容归属

| 模块 | 保存内容 |
| --- | --- |
| 书稿 | 作者章节与笔记 |
| 人物 | 身份、稳定性格、能力限制、关系、知识与声音 |
| 事件 | 单次行动的前置、参与者、认知差、过程和结果 |
| 世界观 | 国家、地区、组织、制度与长期关系 |
| 设定 | 可复用的地点、技术、道具、程序与写作规则 |

新建资料只插入可编辑的栏目标题。作者可以自由增删栏目。资料的子文档从目录项右键菜单创建；父子保持相同类型，各自保存正文。人物子文档不作为另一个独立参与人物。

## 属性与引用

- 标题下方直接选择“待定 / 已定案”。正文不因状态改变而改写。
- “属性与关联”打开原生 Sheet，编辑标识、标签及关联文档；标签用英文或中文逗号分隔。
- 事件额外保存故事时间、参与人物和前置事件。故事时间是作者填写的文本锚点，可以采用相对时间，无需虚构公历日期。
- 事件标识与目录顺序独立。右键上移 / 下移决定同级显示顺序，不按事件编号重新排序。
- 关联使用文档 UUID；引用不复制源正文，改名后仍能找到原文档。关联旁的打开按钮进入源文档；属性中也能查看谁引用了当前文档。
- 关联可以双向；事件的前置链与文档父子链必须无环。循环前置选项在界面禁用；缺失目标、错误类型和循环前置仍由领域服务校验，拒绝本次修改并保留原记录。

每份事实由作者在一个来源维护，其他资料以引用连接。章节中的临时写法不会自动追认为定案，也不会自动回写人物、事件或世界观。

## 保存与兼容

正文继续保存为独立 UTF-8 文本。纯章节 / 笔记作品仍写格式 1；包含人物、事件等资料后写格式 2。新客户端读取两种格式，保持作品 ID、文档 ID、原文、换行和空格。旧版格式 1 客户端会拒绝格式 2，不能用旧版覆盖保存新资料作品。

资料保存于作者的本地作品包。公开仓库只包含代码、空模板和合成测试；私人作品不作为运行示例或测试 Fixture。当前没有批量导入 Markdown 目录、Markdown 预览或跨端同步。
