# Novel Engine 0.0.1

## 当前原生阶段

- macOS 原生写作工作区：SwiftUI，正文由 NSTextView 适配。
- 创建和打开作品、保存及重新打开；作品使用 `.novelengine` 文件包。
- 新建章节、笔记；编辑作品名、标题、正文与摘要；搜索和调整文档顺序。
- 书稿、正文、章节信息使用同一套区域布局；侧栏也能拆分与 Join。区域左侧选择器可切换内容类型。
- 右上角直接提供左、右、上、下按钮，操作当前活动区域；每个区域直接提供向右、向下按钮，局部操作针对本区。
- 点击区域即可激活。拆分、合并、打开文档后，键盘焦点必须进入操作结果区域，不能只移动选中标记。
- 分隔条可拖动、方向键调整、双击均分；右键第一层显示 Join 操作。
- Join 由源区域向相邻方向扩展，保留源区域的内容类型，只关闭完整共边的一个目标视图；四格布局可以分行合并。关闭区域也不删除文档，最后一区不能关闭。
- 布局撤销与正文撤销独立；作者内容不得被分栏或主题操作删除。专注模式保留原有布局。
- DFW 日间 / 夜间 / 跟随系统；正文字体与字号设置；专注模式和可关闭的章节信息区域。
- 系统文件菜单、保存面板、输入法、文本选择、复制粘贴和撤销。
- 仅显示真实字数与段落数。空白作品不填入小说内容。

## 数据约束

作者正文按 UTF-8 字节往返，不自动去空格、改标点或生成内容。格式损坏、正文缺失、未知版本必须报错，不创建空内容覆盖原文件。布局偏好只存文档 ID、分栏和比例，不写入作品正文。

## 后续范围

iPhone、用户提出的 Duo、iPad、Windows 和 Android 平板仍是目标平台，尚无对应客户端构建。同步、修订冲突、人物与世界观管理、导入导出扩展另行实施。当前不接入 AI，不创建相关设置或依赖。

当前不提供删除章节入口，避免在尚无恢复 / 修订机制时加入不可恢复的正文删除。只实现真实可用的控件。
