# Novel Engine 0.0.1

## 当前原生阶段

- macOS 原生写作工作区：SwiftUI，正文由 NSTextView 适配。
- 创建和打开作品、保存及重新打开；作品使用 `.novelengine` 文件包。
- 新建章节、笔记；编辑作品名、标题、正文与摘要；搜索和调整文档顺序。
- 左侧纵向切换书稿、人物、事件、世界观、设定；人物及资料支持总卡与同类型子文档。
- 资料正文使用可自由编辑的分节文本；空模板只提供栏目，不生成小说内容。
- 资料具有待定 / 已定案状态、标识、标签与文档引用；事件另有故事时间、参与人物和前置事件。
- 资料与章节共用编辑器、分栏和保存机制。显式关联按稳定 UUID 保存；事件编号不决定时间顺序。
- 左侧资料导航固定，不参与分栏。编辑器包括主区与一个辅助区，两个区域独立选择具体文档。
- 右上角只有一组左、右、上、下按钮；首次创建辅助区，之后移动现有辅助区，不递归拆分。
- 每区标题提供文档选择器。只有辅助区有关闭按钮；关闭后主区铺满，不删除文档。
- 点击正文或标题激活对应编辑区；从目录打开文档进入活动编辑区；区域选择器只改变所属区域。
- 分隔条支持拖动、方向键和双击均分；不重复提供拆分和合并菜单。
- 布局撤销与正文撤销独立；作者内容不得被位置、关闭或主题操作删除。专注模式保留原有布局。
- DFW 日间 / 夜间 / 跟随系统；正文字体与字号设置；文档信息及摘要使用原生 Sheet。
- 系统文件菜单、保存面板、输入法、文本选择、复制粘贴和撤销。
- 仅显示真实字数与段落数。空白作品不填入小说内容。

## 数据约束

作者正文按 UTF-8 字节往返，不自动去空格、改标点或生成内容。格式损坏、正文缺失、未知版本必须报错，不创建空内容覆盖原文件。布局偏好只存文档 ID、分栏和比例，不写入作品正文。

## 后续范围

iPhone、用户提出的 Duo、iPad、Windows 和 Android 平板仍是目标平台，尚无对应客户端构建。同步、修订冲突、Markdown 目录导入及其他导出扩展另行实施。当前不接入 AI，不创建相关设置或依赖。

当前不提供删除章节入口，避免在尚无恢复 / 修订机制时加入不可恢复的正文删除。只实现真实可用的控件。
