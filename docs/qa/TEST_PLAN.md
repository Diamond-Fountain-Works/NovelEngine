| 层 | 检查 |
| --- | --- |
| NovelDomain / Application | 空白作品、显式编辑、Unicode 与空白不改写、无效 ID、幂等空编辑、合法排序 |

| NSTextView 适配 | 原生输入回写、正文撤销、marked text 提交边界、只切焦点不输入、禁止自动改写、DFW 字体注册 |
| 会话与分隔条 | 活动编辑区、明确的文档打开目标、布局持久恢复、信息 Sheet、方向键调整 |
| 本机偏好迁移 | 旧多区域及 editor-only 快照迁入双区，保留选中文档及 pane ID、旧 key 和作品正文 |

| Mac 文件适配 | FileWrapper 往返、真实磁盘保存再打开、拒绝符号链接、拒绝坏文件包 |
| 工程 | 文档链接、模块依赖方向、相对 Package 路径、Bundle 版本与类型声明 |

## 实际 macOS 操作

1. 启动开发 App，左侧只有一份固定资料导航，正文区域没有局部分栏按钮。
2. 打开合成旧作品，确认章节、人物子文档及事件关联仍在。
3. 顶部创建右侧辅助区，从该区标题选择人物；主区保留原章节。
4. 依次点击上下左右，重复点击同一方向，始终只有两区，文档与 pane ID 不变。
5. 点击主区后从目录打开另一文档，辅助区内容不变；选择器打开只影响自己的区域。
6. 拖动、方向键及双击调整两区比例；760pt 窄窗口检查标题、属性和关闭按钮。
7. 关闭辅助区，主区铺满；布局撤销恢复辅助区及其原文档。
8. 两区分别输入，验证文本撤销；布局撤销不回滚作者内容。
9. 打开信息 Sheet 编辑摘要并关闭；进入专注模式后退出，检查布局保留。
10. Cmd+S、关闭、重新启动并打开，逐字比较文本、状态、关联与恢复的布局。
11. 日间 / 夜间 / 跟随系统检查并恢复原外观；所有截图为 Candidate。

浏览器原型测试与原生 UI 检查分开报告。真实中文输入法候选窗口、旧版 macOS、异常进程退出恢复、跨设备同步均需要独立验收。

## 资料模块验收

- 格式 1 的固定历史 Fixture 保留原 ID 与原始 UTF-8；添加资料后格式 2 完整往返。
- 人物总卡、独立子文档；事件的参与人物 / 前置 / 通用引用；无效目标、错误类型及循环关系原子拒绝。
- 人物子文档不能作为另一个参与人物；资料字数不增加章节正文统计。
- 搜索标题、标识及标签，匹配子文档时保留父级；事件代码不决定顺序。
- 固定导航模块不随编辑区选择变化；重启恢复模块但不保存搜索词。
- 属性 Sheet 打开后输入不进入正文；无改动关闭不产生 Document Binding 写入。
- 用真实窗口完成创建、属性与标签、子文档、关联跳转、与章节对照分栏、保存及重启。
- 检查日间 / 夜间、最小窗口和短区域，截图只记 Candidate。

## 托管作品库

- 格式 3 资料、长简介 UTF-8、合作者稳定 ID；旧格式 1 / 2 仍可读取。
- 创建、重复保存、重启与两份快照保留；半成品未发布快照不替代原记录。
- 旧修订写入和外部直接修改被拒绝，未保存草稿仍可导出。
- 原图完整字节、SHA-256、缩略图独立；坏图、符号链接与损坏媒体被拒绝。
- ne 导出 / 回读、旧 novelengine 导入、相同作品去重和不同内容不覆盖。
- 高频编辑后 flush 保存最新值；保存失败不能显示已保存；正常退出等待写入。
- QA 缺少隔离目录或误指向正式库时停止启动。
- 正常界面验证创建、长简介、署名 / 分工、封面选择、写作、自动保存、关闭窗口、重启、导入和导出。
- 作品库及作品主页检查日夜、760pt 宽窗口与滚动；截图仅为 Candidate。
