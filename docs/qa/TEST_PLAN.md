# 原生测试计划

## 自动化

| 层 | 检查 |
| --- | --- |
| NovelDomain / Application | 空白作品、显式编辑、Unicode 与空白不改写、无效 ID、幂等空编辑、合法排序 |
| NovelStorage | 作品包往返、独立章节与笔记、稳定 UUID、未知格式、重复 ID、缺失正文、损坏 UTF-8、大正文 |
| NovelWorkspace | 四向分栏、指定非活动组拆分、跨父区域 Join、按鼠标行选择邻居、不匹配边拒绝合并、单组关闭、正文引用、布局撤销、重置、比例边界和布局恢复 |
| NSTextView 适配 | 原生输入回写、正文撤销、marked text 提交边界、只切焦点不输入、禁止自动改写、DFW 字体注册 |
| 会话与分隔条 | 活动组与文档类型、显式局部操作目标、布局持久恢复、原生右键坐标与菜单派发、方向键调整 |
| 统一区域 | 侧栏 / 正文双向 Join、侧栏拆分与类型切换、完整物理矩形覆盖、旧 pane 默认类型、旧布局一次性迁移 |
| 键盘目标 | 程序拆分后的新区域 focus request、实际 first responder、取消过时请求、标题输入不被手动激活抢焦点 |
| Mac 文件适配 | FileWrapper 往返、真实磁盘保存再打开、拒绝符号链接、拒绝坏文件包 |
| 工程 | 文档链接、模块依赖方向、相对 Package 路径、Bundle 版本与类型声明 |

## 实际 macOS 操作

1. 启动构建的开发 App，创建空白作品。
2. 编辑中文标题和正文，新建章节 / 笔记，在两个分栏分别编辑并验证共享引用。
3. 检查顶部四个方向按钮及每组直接向右、向下按钮；不需要打开母菜单才能拆分。
4. 两栏打开不同文档，点击其中一栏但不输入，再执行全局拆分；检查作用目标。再从非活动栏的局部按钮拆分。
5. 创建四格布局，在中央分隔线上半段执行 Join Right、撤销；下半段执行 Join Left。每次只关闭一个组，其余区域与文稿保留。
6. 拖动、方向键及双击均分；关闭一组、撤销、专注和退出专注。
7. Cmd+S 使用系统保存面板保存合成作品，关闭窗口后重新打开，逐字比较文本。
8. 日间 / 夜间 / 跟随系统；排版、章节信息及窗口缩放。
9. 分别测试正文撤销、布局撤销；不以布局撤销回滚作者输入。
10. 从书稿侧栏右键 Join，撤销后拆分侧栏，将新区域切换为章节信息。
11. 输入合成正文，拆分后不再点击正文，检查 first responder 已在新区域；回到原区域验证文本撤销 / 重做在拆分及 Join 后仍有效。

浏览器原型测试与原生 UI 检查分开报告。真实中文输入法候选窗口、旧版 macOS、异常进程退出恢复、跨设备同步均需要独立验收。
