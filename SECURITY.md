# Security

Security-sensitive areas include `.novelengine` file parsing, filesystem paths, symbolic links and preservation of author text.

Use the repository's private vulnerability-reporting channel for sensitive findings. Reproduce file-format issues with a minimal synthetic document. Do not attach private manuscripts, credentials or local user logs to public issues.

The app currently stores author-selected local document packages and local UI preferences. Account services, network synchronization and AI integrations are outside v0.0.1.
